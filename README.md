## 👋 About This Project

This isn't just a static website—it's a **fully interactive Operating System simulation** built entirely in the browser. I designed this portfolio to create an immersive experience where recruiters and visitors can explore my projects, skills, and background just like they would on a real desktop.

It demonstrates advanced frontend engineering capabilities, including complex state management, fluid animations, and a component-driven architecture that scales.

## ✨ System Highlights

*   **🖥️ Desktop Environment:** A complete desktop interface with draggable icons, context menus, and a responsive taskbar.
*   **📂 Finder (File System):** A recursive file system simulation allowing deep navigation through project folders and assets.
*   **🖼️ Gallery App:** A custom-built photo viewer to showcase project screenshots with keyboard navigation and grid layouts.
*   **🌐 Safari Browser:** A simulation of a web browser to display certificates and external links within the OS context.
*   **⚡ Optimization:** Engineered for 60FPS animations and instant load times using the latest web standards.
